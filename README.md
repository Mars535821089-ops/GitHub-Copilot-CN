# GitHub Copilot-CN（macOS 独立桌面版）

适用于 GitHub Copilot 独立 macOS 应用 1.1.34（arm64）的非官方简体中文界面补丁源码。本仓库提供 UI 文本审查、翻译、资源重建、结构验证和本地模型库签名修复工具。它不包含 GitHub 官方应用、可执行文件、模型权重、账户数据或签名证书。

**维护状态：**截至 2026-10-31，GitHub Copilot 桌面应用没有文档化的 UI 语言包或本地化扩展接口，不能像 VS Code 一样通过受支持的语言包跟随产品更新。最新支持基线为 1.1.34，其官方 arm64 包、GitHub 签名、主程序和 1,158 个可解码资源均已核对；未知版本或资源指纹仍会停止。运行 `python3 scripts/check-official-release.py` 可交叉核对官方最新稳定版与本机 build/二进制指纹；`python3 scripts/check-upstream.py '/Applications/GitHub Copilot.app'` 则只读检查具体资源。未知资源差异只生成本地候选供审查，不会自动套用到应用包。详情见 [低维护本地化维护方式](docs/低维护本地化维护方式.md)。

## 汉化补全与人工校订

人工校订的 509 条界面文案集中在 `work/localization/reviewed-dictionary.json`，优先于原始词典。98 组完整显示查表对象集中在 `reviewed-display-maps.json`，按模块和完整结构识别，补齐模式、通知位置、会话排序、连接状态、评审结果、工作区进度及工具执行状态等遗漏；保留枚举键、引用和协议值。表情词典补全了英文说明，地区旗帜名称使用 Node.js 自带的 ICU 中文地区名生成；保留原始表情、英文短码、搜索标签和分类 ID。

生成过程与更新差异预览共用 `dictionary.cjs` 合并词典，不再在构建时修改已提交的原始词典。运行时补齐富文本输入框的占位提示、无障碍说明和嵌套界面节点的属性翻译，同时保护用户消息、可编辑内容、代码和终端。

系统事件中的思考时长、压缩对话及移除消息数在客户端显示源头翻译，不改模型正文、用户消息或服务端错误详情。表格画布使用对应版本 Univer 0.24.0 的官方中文资源，只覆盖 UI 资源注册，不改变工作簿语言枚举、单元格、公式或日期解析。七个来源包的版本、SHA-512 和 Apache-2.0 许可随源码保留，构建时无需联网获取语言数据。

1,870 个表情说明已逐项检查为中文。本轮已从官方原版构建、签名并实际安装，也从最终二进制重新提取资源验证；**这仍不等于已验收全部页面或未来云端文案**，当前运行中的旧进程须正常退出重开。

## 已完成范围

- 全量扫描 1,065 个打包 JavaScript 模块；本轮生成包含 19,453 处静态替换、7,472 个 UI 渲染位置和一个独立的官方表格语言资源覆盖边界。
- 处理动态提示、隐藏状态筛选、原生设置元数据、菜单显示文字及七个内置自动化模板；保留路由、枚举、模型 ID、快捷键与用户输入。
- 修复补丁导致的 Foundry Local 动态库签名团队不一致问题：使用同一个有效的本地 Apple 开发签名签署主应用和四个进程内动态库，并保留强化运行时与库验证。
- 本轮 68 项 Node、11 项 Python 测试及 250 个修改模块的结构验证通过。完整历史记录见 docs/中文版完整审查与模型修复结果.md；本轮签名、实际安装和已知边界见 [公开源码复现验证](docs/公开源码复现验证.md)。

这是一套按原版二进制 SHA-256 固定的补丁，不能直接套到其他版本。全量审计会列出剩余英文候选，但不会盲译 CSS、协议、搜索关键词、代码、产品名、终端或用户内容；第三方开发诊断的长说明、部分底层异常及未来云端文案仍可能为英文，不能据静态扫描宣称全产品零漏译。当前窗口的全部实际显示状态及麦克风转录尚未完成现场验收。模型目录测试确认 81 个模型、其中 9 个语音识别模型，但不代表模型已下载或录音成功。

## 本地构建

先运行 `python3 scripts/check-official-release.py`，通过 `gh` 只读交叉核对官方 `github/app` 最新稳定 Release 和更新器 `latest.json`，输出本机版本/build、主程序 SHA-256、官方版本和归档摘要。版本相同**不代表补丁兼容**，仍须运行资源检查和真实源码测试；未知指纹不会因此获准安装。版本不一致返回 3，来源不一致或查询失败返回 2，不修改应用。截至 2026-10-31，官方最新为 [v1.1.34](https://github.com/github/app/releases/tag/v1.1.34)。

需要 macOS arm64、Python 3、Node.js/npm、Xcode 命令行工具、与当前基线指纹完全匹配的官方原版 1.1.34，以及本机有效的 Apple Development 签名身份。先用 security find-identity -v -p codesigning 查看可用身份。使用**未打补丁的官方原版**，不要把现有中文版当作原版输入。

    ./scripts/build-local.sh '/path/to/original/GitHub Copilot.app' 'YOUR_LOCAL_SIGNING_IDENTITY'

脚本核对原版 SHA-256 后在仓库本地保留原版副本，提取 UI 资源、构建汉化、运行测试、生成 dist/GitHub Copilot 中文版.app 并验证签名。它不会安装、退出或重启正在使用的应用，也不会更改系统安全设置。输出目录已被 Git 忽略。首次运行可能需要下载 npm/Python 构建依赖；如果系统默认 Python 不适合，可用 COPILOT_PYTHON 环境变量指定一个 Python 3 解释器。构建不会向翻译服务发送用户内容。

可选的 scripts/restore-original.command 会在正常退出应用后保留当前安装并恢复本地官方原版副本，不会强制关闭或清除用户数据。若只检查模型目录，可使用 scripts/check-model-catalog.sh 传入已签名的应用和同一签名身份。该检查只枚举目录，不下载或选择模型；目录查询可能需要联网。

### 安装与当前窗口生效

**提交源码、生成资源和构建 `.app` 都不会自动改变正在使用的窗口。** 对已审查的旧版中文安装，可在成功构建后运行 `bash scripts/install-local.sh`。脚本只接受已知旧中文版指纹，验证新旧应用标识和本地签名团队，保留完整旧版到 `outputs/installed-backups/时间戳/`，再安装至 `/Applications/GitHub Copilot.app`；未知版本和官方原版不会被覆盖。安装不退出应用，也不读写会话、账号、项目或系统权限。

安装完成后须正常退出并重新打开 GitHub Copilot，旧进程不会自动重新加载嵌入的界面资源。尤其是模式菜单的“交互式 / 规划 / 自动执行”及三条说明、辅助模式的“实验性”标记，现在有真实资源回归测试，不再仅验证词典里存在译文。若要恢复安装前的旧中文版，先正常退出应用，保留当前应用副本，再将安装日志中的完整备份移回原安装位置。

## 目录

- work/localization：词典、AST/UI 显示层转换、原生菜单处理、资源补丁和回归测试。
- work/research/inspect_embedded_ui.py：从用户自己的官方应用提取打包前端资源。
- work/model-diagnosis：模型库加载与目录测试的原生源码及脱敏验收摘要。
- work/runtime：Node 依赖清单与锁文件。
- docs：本机原构建的审查与验收记录，含已知未验收项。
- scripts/check-upstream.py：更新后的本机版本/资源指纹检查与候选译文差异预览；只读应用包。
