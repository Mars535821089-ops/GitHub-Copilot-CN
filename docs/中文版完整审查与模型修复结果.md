# GitHub Copilot 中文版：完整代码审查与模型修复

已更新安装位置：`/Applications/GitHub Copilot.app`，版本 1.1.33。

## 修复范围

- 扫描全部 1065 个 JavaScript 构建模块，处理 16,859 处静态界面文字、7,472 个界面渲染位置。
- 补齐输入框各模式提示、隐藏状态筛选（需要关注/未读/处理中/已完成）、动态账号归属说明、分类标签、日期及时间的中文显示。
- 本机原生实验性目录的 275 项文本均有明确映射；另审查 304 项原生固定文本候选。
- 7 个内置自动化模板的初始名称与提示内容已处理；保留 `/chronicle cost-tips` 等可执行命令。仅修改应用内置模板，不改用户已保存的任务、提示词和对话。
- 工具/API 标识、路由、功能枚举、账号、模型 ID、快捷键行为和设置值保持不变；人名、产品名、代码等按语义保留。

## 语音模型故障

已在应用日志中确认真实原因：先前中文补丁的主程序采用临时签名，模型动态库保留官方签名，两者团队不一致，模型库被系统拒绝加载。它并不是截图泛化错误文案所暗示的“组织网络限制”。

本次将修改后的主程序和其进程内模型库统一使用本机现有合法开发签名，保留强化运行时和动态库验证，没有关闭系统安全机制。使用最终应用中的实际模型库，在启用强化运行时的独立签名测试程序中，成功读取 **81 个模型、9 个语音识别模型**，原默认语音模型仍存在。没有改换提供商、伪造模型列表或更改系统代理/节点。

这次验证覆盖目录与本地库加载。未执行麦克风录音转录，也未声称模型已下载或录音已经成功。

## 验证与生效

- 38 项行为和回归测试通过。
- 249 个修改模块的语法和结构验证通过；新增部分仅为显示层映射。
- 已安装包与候选构建的哈希一致，严格签名验证通过，主程序和模型库签名团队一致。
- 本轮没有启动、关闭、重启、重载应用，没有要求重复授权。下次正常完全退出并重新打开时加载本次安装内容。
- 没有把静态代码覆盖当作整个应用所有未来云端动态文案的永久全覆盖保证。实际麦克风和当前窗口的现场验收尚未执行。
